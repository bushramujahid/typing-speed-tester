# Typing Speed Tester

A simple Python typing speed test that measures how fast you type and how accurate you are.

## Features

- Random sentence selection
- Tracks time taken to type
- Calculates typing speed in words per minute (WPM)
- Measures accuracy based on correct characters typed
- Easy console-based interface

## How it works

The program picks a random sentence from a predefined list, shows it to the user, and then asks them to type it as quickly as possible. After submission, it prints:

- Time taken
- Number of words
- Typing speed (WPM)
- Accuracy percentage

## Run the project

From the project folder, run:

```bash
python main.py
```

## Project files

- [main.py](main.py) - contains the typing test logic
